Politique de confidentialité

Cette politique explique quelles données peuvent être utilisées par Gwen et comment elles sont traitées.

Données utilisées

Gwen peut traiter les messages envoyés dans les serveurs Discord où le bot est présent afin de fournir ses fonctionnalités.

Utilisation des données

Les données sont utilisées uniquement pour faire fonctionner les fonctionnalités de Gwen et améliorer son fonctionnement.

Conservation des données

Les données ne sont conservées que lorsque cela est nécessaire au fonctionnement du service.

Contact

Pour toute question concernant la confidentialité, veuillez contacter l'équipe de Gwen.
